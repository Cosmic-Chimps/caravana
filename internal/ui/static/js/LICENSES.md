# Third-party scripts in this folder

`htmx.min.js` and `sse.min.js` are vendored by `tools/ui-vendor.sh` from the npm registry's
tarballs, pinned by version and SHA-256 in `tools/ui-vendor.versions`. `console.js` is
caravana's own.
